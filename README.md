# USEONCE 🌿
### Need it. Use it. Return it.

**USEONCE** is a website concept that encourages people to borrow items they need occasionally instead of buying things they may rarely use.

From cameras and kitchen appliances to camping equipment and curated kits, USEONCE makes borrowing a more convenient and thoughtful alternative to owning everything.

## ✨ About the Project

USEONCE was created to explore how a simple website can help people access useful items, reduce unnecessary purchases, and make better use of things that already exist.

The project focuses on a clean, welcoming design with warm cream backgrounds, olive-green accents, and elegant serif typography.

## 🎯 Project Goals

- Encourage borrowing instead of unnecessary buying.
- Make useful items easier to discover.
- Present borrowing kits for specific needs and occasions.
- Provide clear item descriptions and condition information.
- Promote responsible borrowing, collection, and returns.

## 🛠️ Built With

- **HTML5** for page structure.
- **CSS3** for styling and layouts.
- **Font Awesome** for icons.
- **GitHub Pages** for deployment.

## 📄 Website Pages

- **Home:** Introduces USEONCE and highlights popular items and occasions.
- **Explore Items:** Displays available items to discover.
- **Item Details:** Presents item descriptions, daily prices, and condition information.
- **List an Item:** Provides a visual form for listing an item.
- **Saved Items:** A page concept for keeping track of interesting items.
- **Account:** A visual account page concept.
- **Trust & Safety:** Explains responsible borrowing and lending.
- **Our Mission:** Shares the purpose and values behind USEONCE.
- **Borrow Confirmation:** Illustrates the steps after selecting an item.

## 🎨 Design

The website uses a warm, minimal visual identity inspired by sustainability and thoughtful consumption.

- **Primary colour:** Olive green (`#4F5D2F`)
- **Background:** Warm cream
- **Typography:** Georgia serif headings
- **Layout:** Rounded cards, subtle borders, and clear spacing

## ⚙️ How to View the Project

1. Open the live website using the GitHub Pages link, when available.
2. Alternatively, download or clone this repository.
3. Open `index.html` in your browser.

## 📌 Project Limitations

USEONCE is a front-end website prototype built with HTML and CSS only. It does not currently include a backend or JavaScript functionality.

Forms, account features, saved items, and borrowing confirmations are visual demonstrations rather than fully functional services. No real reservations or payments are processed.

## 🌱 Future Improvements

- Add a backend for managing items and users.
- Implement functional borrowing requests and availability.
- Introduce secure user accounts.
- Enable real saved items and item listings.
- Develop a collection and return management system.

## 💚 Our Idea

You don't need to own everything you use.
